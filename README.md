# 微信公众号写作发布插件

本地 Codex 插件，用于把笔记、提纲、资料或现有文章整理成公众号内容，生成微信兼容的内联样式 HTML，并通过公众号官方 API 同步到草稿箱和提交发布。

## 功能

- 直接排版现有内容，不强制改写
- 根据整理材料进行编辑或成文
- `clean`、`business`、`warm` 三套公众号主题
- 默认手机稳定版：独立段落样式、标准左对齐、充足行高；可用 `--rich` 保留原富排版
- 手机宽度 HTML 预览
- 上传正文图片和封面素材
- 创建公众号草稿
- 明确确认后提交发布
- 查询发布结果

## 配置

启用 MCP 服务前，在 Codex 的插件环境变量中配置：

```text
WECHAT_APP_ID=公众号 AppID
WECHAT_APP_SECRET=公众号 AppSecret
```

也可以临时提供 `WECHAT_ACCESS_TOKEN`。不要把密钥写进文章或提交到 Git。

账号还需在微信公众平台配置接口权限和 IP 白名单。默认工作流只创建草稿，发布必须再次确认。

## 本地排版测试

```bash
node scripts/format-wechat.mjs --input article.md --output preview.html --theme clean
```

默认生成适合手动复制到公众号编辑器的保守排版。`--rich` 使用旧版富排版，需要额外核对手机端效果。Markdown 行内链接在稳定版会变为独立的“原文链接”行，仍保留目标地址；加粗与行内代码标记会转成普通文字。

本地 HTML 预览不能代替公众号编辑器的手机检测。手动粘贴时，本地图片可能不会自动进入公众号，应在编辑器中另行插入。通过 API 创建草稿前，插件会拒绝含相对路径、`file:` 或 data URI 图片的正文；请先上传正文图片并替换为 HTTPS 地址。
